# 🌐 Portafolio Personal - Alejandro Florea

¡Bienvenido al repositorio de mi página web personal y portafolio! Esta plataforma está diseñada de forma sencilla e interactiva para mostrar quién soy, mis proyectos destacados y las vías de contacto.

Puedes ver la web en directo aquí: [alejandroflorea.github.io](https://alejandroflorea.github.io)

---

## 🎯 ¿Qué incluye la web?

- **Presentación:** Un resumen sobre mi perfil, intereses y formación.
- **Portafolio de Proyectos:** Sección interactiva con tarjetas que muestran mis proyectos destacados, descripciones y enlaces.
- **Sección de Habilidades:** Resumen visual de mis conocimientos técnicos y herramientas.
- **Contacto / Redes:** Enlaces directos a mi correo, GitHub, LinkedIn y otras plataformas.
- **Diseño Responsive:** Adaptado para visualizarse correctamente en ordenadores, tablets y dispositivos móviles.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura y maquetación semántica.
- **CSS3:** Estilos, layout responsive y animaciones.
- **JavaScript (ES6+):** Lógica interactiva de la interfaz.
